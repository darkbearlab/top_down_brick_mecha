# 重火力測試模式 規劃（草案）

參考叛擊士（Brigador）的戰鬥節奏：子彈接近真實速度、機槍彈量大但很快打光、敵人少但耐打、臼砲 / 迫擊砲、大量可破壞地形。
**完全獨立的模式**：自己的地圖產生器、自己的數值覆蓋。遠征、無盡、觀戰、無頭模擬的數字和行為一律不變。

## 要驗證的問題
1. 子彈快到躲不掉之後，防守改成「掩體、斷視線、先打誰」，好不好玩？
2. 敵人少而耐打 + 玩家火力大但彈藥燒得快：一場交戰的節奏（幾秒、打幾輪、要不要撤退換彈）。
3. 地形被打爛（掩體消失、迫擊砲逼出掩體）對戰鬥的影響有多大。
4. 哪些改動值得搬回主遊戲，哪些只適合這個模式。

## 組成
### 1. 入口
- `MODE.name = 'heavy'`，`__dbg.startHeavy(seed)`；主選單「測試」子選單多一個「重火力測試」按鈕（和試玩場放一起）。
- 結束 / 回主選單時把數值覆蓋還原。

### 2. 數值覆蓋層（新檔 `src/heavy.js`）
- 一份 `HEAVY` 設定：子彈速度倍率、敵人子彈減速（現在 `ENEMY_SPEED = 0.55`）、機槍射速 / 彈量、敵人耐久倍率、玩家耐久倍率…。
- 做法：模式開始時對 `WEAPONS` 做覆蓋、記下原值，離開時還原；`weapons.js` 只多讀一個預設 1 的倍率（乘 1 結果完全一樣 → 模擬不變）。
- 先列的起始值（之後在模式裡調）：

| 項目 | 現在 | 測試起始值 |
|---|---|---|
| 子彈速度（機槍 / 機砲） | 36 / 32 格/秒 | 約 2 倍（射程不變 → 飛行時間減半） |
| 敵人子彈 | 玩家的 0.55 倍 | 1 倍（不再刻意放慢） |
| 機槍 | 每 0.07 秒、720 發（≈50 秒） | 每 0.025 秒、1200 發（≈30 秒） |
| 敵人數量 / 耐久 | 一隊 3 台 | 一隊 1～2 台、耐久約 2～3 倍 |
| 交戰距離 | AI 3～13 格 | 拉到 10～20 格（大約一個畫面） |

- 射速變快時每發傷害、後座、散布、音效頻率也要一起看（太密的音效要合併）。

### 3. 地圖產生器（新函式，`src/stagegen.js` 或新檔）
- 單層、中等大小（約 96 × 72 格），密集城市街區：3～4 格寬的街道 + 方格街廓，街廓裡塞 1～4 層的可破壞建築（沿用 `buildings.js`），偶爾廣場、停車場。
- 外圍圍牆不可破壞，裡面幾乎全部可以打爛。
- 輸出格式跟現在 `genStage` 一樣（`layers`、`buildings`、`spawn`…），沿用 `resetWorld(map)` 那條路蓋場景。
- 敵人放法：簡化版遠征小隊（待命 → 發現 → 醒來），不做傳送門、箱子、增援，先專心看交戰。

### 4. 敵人
- 少量、耐打、分工：機槍 / 機砲步行機、戰車（履帶、加農砲）、重型機（王牌級裝備）、**迫擊砲**。
- 新武器 **迫擊砲**（敵人用，低階版先做；之後可以給玩家）：
  - 拋物線、落點預告圈（跟燒夷彈同一套），爆風打人也打建築（`blastBuildings`），可以越過建築打到後面。
  - 射程長（20～28 格），射速慢，會把躲在掩體後的玩家逼出來。
- 派系互打照遠征的規則（如果放蟲）。

### 5. 地形破壞
- 確認現在的破壞量級：機槍連打多久會打穿一面牆、加農砲 / 迫擊砲一發打掉多少。
- 可能需要：重武器對建築的傷害倍率（只在這個模式）、倒塌時的瓦礫擋不擋子彈（現在不擋）。

### 6. 量測
- 在模式裡記：每場交戰時間、玩家打死每種敵人要幾秒（TTK）、被一隊集火能撐幾秒、彈藥消耗速度、開火時的距離分布。
- 開局後按一個鍵（或 `__dbg.heavyStats()`）印出表格，和遠征模式並排比較。
- 能用無頭模擬量的部分（TTK、射程）加一個 `tools/sim` 腳本，套同一份 `HEAVY` 設定。

## 分階段（每階段做完給你看再往下）
1. **骨架**：模式入口 + 街區地圖產生器 + 現有敵人照放（數值還沒改）。看地圖的密度和交戰距離。
2. **數值覆蓋**：子彈速度、敵人子彈不減速、機槍射速 / 彈量、敵人少而耐打。實際玩，看躲不掉子彈之後的手感。
3. **迫擊砲 + 地形破壞量級**。
4. **量測工具** + 數字表，決定哪些要搬回主遊戲。

## 規則
- 主遊戲的數值不改；每次提交前跑 `duel.mjs`（突擊型 vs 狙擊型 10 場 seed 1）確認跟改之前一樣。
- 不寫 localStorage；動畫相關照 `docs/ANIM_SPEC.md` 的規則。
- 這是參考節奏的原創模式，不做叛擊士的關卡、載具、美術。

## 要你決定的
- 模式名稱（暫定「重火力測試」）。
- 第 2 階段的起始數值要不要照上表，還是你有想要的數字（例如子彈要快到幾乎即時命中）。
- 玩家機體：用整備裡的配裝，還是固定給一套測試用配裝（比較好比較）。
