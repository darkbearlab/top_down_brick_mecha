# 據點戰（3 對 3 + 據點）規劃

2026-11-27 草案；同日定案並做出第一版（全 AI 觀戰，src/conquest.js、tools/sim/conquest.mjs）。

**定案（使用者）**：照第 9 節的建議；據點的原生守軍 = 蟲族（壓制蟲巢後把蟲族當資源收割）；九座不同功能的巢穴散在各處；雜魚增援從自己的大本營出發（增援條）；王牌機不放擊墜特寫、重組間隔短。
玩家 + 2 台 AI 隊友 對 3 台 AI；地圖上有原生防禦設施守著的中立據點，打下守軍、佔領之後，持有方得到定期空投、buff、對手 debuff。
節奏參考：MOBA（兵線、據點、推進）＋ Battlefront 征服（佔點、計分、重生）。用新數值（heavy.js）。

## 1. 一場的流程

1. 開場：雙方各 3 台主力機（王牌級）從自己的基地出發；中間的據點都是**中立**，各自被一組原生守軍佔著（砲塔、碉堡、工事、駐守的雜魚）。
2. 打下守軍：據點的守軍全滅（或只剩砲塔被打爆）→ 據點變成「可佔領」。原生守軍敵視雙方，誰靠近打誰。
3. 佔領：站在據點圈裡讀條（約 6 秒；多一台己方主力 ×1.5 快；圈裡有敵方主力就暫停）。佔下 → 據點換成自己的顏色。
4. 持有的好處（第 4 節）：定期空投己方雜魚、全隊 buff、對方 debuff。
5. 搶奪：敵方據點要先打掉那邊的己方雜魚 / 打爆己方蓋的砲塔，再站圈把它「中立化」，然後才能佔。
6. 勝利：**計分制**（每持有一個據點每秒 +1，先到 600 分，或 12 分鐘到時分數高的贏）。基地不能佔（各自的重生點）。
7. 重生：主力機損毀 → 機體重組（跟遠征的故事一致），等 8 秒 + 每多死一次 +2 秒（上限 16），從基地或己方持有、沒在交戰的據點出發。

## 2. 地圖

- 用遠征的地圖產生器（mapgen.js 的分區、隘口、城市街區 fillBlocks / streetCuts），加一個「對稱」選項：先生成半張、左右鏡射（或 180° 旋轉）→ 公平。
- 大小：大場地 96×72（已鎖定的尺寸，不另開新尺寸）。
- 配置（第一版）：雙方基地各在一端；中間 3 個據點（上路 / 中央 / 下路），中央那個最值錢也最難打。之後可以加到 5 個。
- 據點：半徑約 4 格的圈；周圍用遠征的 `fortify`（工事、掩體）蓋防禦設施；路線之間有可破壞的建築當掩體。
- 迷霧：先關掉（對戰模式要公平、AI 也不吃迷霧）；之後可以做「己方單位看得到的地方才亮」。

## 3. 單位

| 角色 | 來源 | 備註 |
|---|---|---|
| 主力機 ×6 | 玩家配裝 + 王牌配裝（觀戰的那組） | AI 用王牌戰術（AI_TUNE.ace / aware / discipline）＋新的目標層（第 5 節） |
| 原生守軍 | 遠征的守備小隊（碉堡、前哨站、砲塔、盾兵…） | 第三方陣營，敵視雙方；不會重生 |
| 據點空投的雜魚 | 雜魚包（SQUADS），每隊最多 3 台 | 往下一個目標據點推進（兵線）；剛調慢到 ×0.7 → 適合當小兵 |
| 己方砲塔（之後） | 砲塔（turret） | 佔下據點後可以花資源蓋 |

隊伍：玩家方 `blue`、對方 `red`、原生守軍 `native`。

注意：現在很多地方用 `team === 'player'` 判斷「是玩家」（音效、鎖定才射、子彈顏色、HUD）。AI 隊友不能用 `player` 隊伍 → 要分出 `isPlayer(m)` 跟 `team`（敵我判斷 `hostilesOf` 已經是照隊伍比，三方沒問題）。

## 4. 巢穴（已實作，src/conquest.js HIVES）

3 × 3 排列（x、z = -22 / 0 / 22），點對稱配置（轉 180° 是同一種）：

| 位置 | 種類 | 效果（每多一座再疊一次） |
|---|---|---|
| 正中央 | 母巢 | 增援條 +2 倍速、得分 ×2 |
| 兩邊大本營前（±22, 0） | 增援巢 | 增援條 +1 倍速 |
| 對角一組 | 酸腺巢 | 全隊傷害 +12% |
| 另一組對角 | 甲殼巢 | 全隊承受傷害 ×0.88 |
| 大道北 | 神經巢 | 全隊極速 +8% |
| 大道南 | 發光巢 | 全隊能量回復 +30% |

- 增援條：什麼都沒有 90 秒滿一次；滿了從自己的大本營空投一隊隨機雜魚（一方最多 12 台）。
- 得分：每座持有的巢穴每秒 0.35 分（母巢 0.7），先到 600 分。
- 主力機重組：4 秒 + 每多死一次 1 秒（最多 8 秒），不放擊墜特寫。
- 防雪球：落後 60 分以上 → 重組、增援條時間 ×0.8。

## 5. AI：目標層（最大的工作量）

現在的王牌只會「挑一台敵人打」。這個模式要在上面加一層「去哪裡」：

- **隊伍指揮（每 2 秒一次，雙方各一個）**：替每台主力機挑任務：
  - 攻：去某個中立或敵方據點（照價值 ÷ 距離，避開敵方主力集中的地方）。
  - 守：己方據點正在被讀條、或附近有敵方主力 → 最近的 1～2 台回防。
  - 會合：2 台去同一個目標（集火、互相掩護），第 3 台去別的。
- **個別機體**：有任務時，沒有敵人在附近就照路線走去任務點（用現有的流場 / 路線）；到了站在圈裡、找掩體；遇到敵人照現在的王牌戰術打，但「理想位置」偏向據點圈內。
- **玩家隊友**：同一套指揮，但會參考玩家：玩家去哪個據點，就派 1 台跟過去；玩家可以下簡單指令（第二版：跟我、守這裡、攻那裡）。
- **雜魚（兵線）**：空投後往指揮指定的下一個據點走，路上遇到敵人就打（現在的雜魚 AI＋lanes 散開接近）。

可參考的現成東西：src/brains 的 2v2 隊伍大腦（lib-a-team：同一套評分自然集火、跟上隊友的目標）。

## 6. 介面

- 上方：雙方分數條、每個據點的狀態圖示（顏色、讀條中閃爍、正在交戰）。
- 小地圖：據點、己方主力位置。
- 主力機損毀：重組倒數、選重生點（基地 / 己方據點）。
- 開場：選配裝（現有的配裝畫面）→ 隊友、對手的配裝從王牌配裝裡隨機（或讓玩家挑隊友）。

## 7. 效能

- 同時：6 台主力 + 最多 24 台雙方雜魚 + 原生守軍 ×（3 據點 × 3～5 台）≈ 45 台，比觀戰重很多。
- 上限：雜魚一方 12 台；原生守軍被打掉不重生；遠處的雜魚降低 AI 更新頻率（每 2～3 幀想一次）。
- 先用無頭模擬量每幀時間，再決定上限。

## 8. 開發順序

1. **全 AI 觀戰版**（3 對 3 + 據點，沒有玩家）：對稱地圖、據點、原生守軍、佔領讀條、計分、重生、隊伍指揮。看 AI 會不會卡住、一場多久、會不會一面倒。
2. **無頭模擬**（tools/sim）：跑很多場量平均時長、勝負分布、落後方翻盤率、每幀時間。
3. **加入玩家**：玩家取代藍方一台；`isPlayer` 拆開；HUD、重生畫面。
4. **據點好處第二輪**：補給、buff、debuff、玩家對隊友的簡單指令。
5. **選單入口、平衡**。
