## 結果整理（第一輪 + 雜魚）
- 一對一勝負關鍵（兩個代理的結論一致）：
  1. 躲不躲得掉：電腦的子彈 ×0.55 很慢、一直橫移就閃掉；真正造成傷害的是全速的飛彈 / 火箭和瞬間命中的脈衝光束
  2. 盾牌：擋下的攻擊不會失衡；繞到沒盾的那一側打是決勝點（同一套機體 32–8 → 119–1）；盾 459 耐久是消耗品，破了就開始連續被火箭打到失衡
  3. 裝甲剋制影響整場：鏡面讓對方脈衝 ×0.65（承受從 ~490 降到 ~265）
  4. 脈衝照射中轉身 ×0.4 → 推進橫閃躲得掉（同機體對打 0–3/40 → 31–33/40）
- 對雜魚（各 10 場，難度 hard）：
  - 單一小隊（19 種）：alpha / beta 全部 100%，大多幾乎沒受傷（保持 12–19 格，雜魚的子彈飛不到）
  - 三個普通小隊一起（10–12 台）：100%
  - 精英小隊 ×2 + 重裝隊：alpha / beta 自己的機體只有 40%；但同一個大腦開突擊型 → alpha 100%、beta 80%（盾 + 單體脈衝怕被包圍，霰彈 / 火箭 / 範圍傷害適合打群）
  - 精英 ×3 + 砲車隊 + 重裝隊：0%
  - 對照：突擊型 + 內建 AI 對三小隊 10%、對精英包 0% → 大腦差距非常大

## 第二輪結果（個性機體）
主對話用另一個種子（3）獨立驗證雜魚關卡（5 組 × 10 場）：
| 機體 | 配裝重點 | 雜魚總計 | 精英包 |
|---|---|---|---|
| berserker 狂戰士 | 打樁拳 + 光束劍 + 雙火箭、全複合 | 98% | 9/10 |
| sniper 狙擊手 | 雙狙擊槍 + 雙直射飛彈 | 100% | 10/10 |
| artillery 重砲手 | 長距鎖定頭、垂直飛彈 + 燒夷彈、機砲 + 霰彈 | 92% | 7/10 |
| knight 騎士 | 騎槍 + 盾（主題允許）+ 直射飛彈、全陶瓷 | 84% | 4/10 |
| arsonist 縱火犯 | 雙火焰噴射器 + 燒夷彈 + 直射飛彈、全陶瓷 | 84% | 3/10 |
| missileer 飛彈指揮官 | 長距鎖定頭、垂直 + 直射飛彈、機槍 + 機砲 | 94% | 10/10 |
- 代理的心得：從整個 enemies[] 挑目標（先殺輸出高的，狂戰士對精英包 2/6 → 19/20）；裝甲照「實際被什麼打」選（雜魚的化學飛彈是大宗 → 陶瓷）；用 16 方向打分選移動（距離、被幾台看到、空間）取代單純風箏；利用雜魚 AI 自己會走到 6–10 格（騎士守株待兔）
- 一對一（代理的選配）：飛彈指揮官對狙擊手 20/20、對重砲手 19/20、對狂戰士 8/20；狂戰士、狙擊手對騎士 10–0；騎士、縱火犯對王牌機幾乎全輸（為打群設計）
- 發現：api.clearAhead 只看 0.8 倍機體半徑，騎槍衝刺會擦到轉角（beta 自己改用全寬檢查，自傷 ~50 → ~1）
