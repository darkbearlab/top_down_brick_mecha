# 第三階段：代理設計機體 + 大腦互打（進度紀錄）

這份檔案記錄進度，中斷後照這裡接著做。

## 目標
1. 兩個代理（alpha、beta）各自設計一台機體（配裝 JSON）和一個大腦，互相對打、看對方的設計再改，迭代幾輪

3. 做出「特定個性」的大腦，配給特定主題的機體（之後可以放進遊戲）

## 結果整理（第一輪 + 雜魚）
- 一對一勝負關鍵（兩個代理的結論一致）：
  1. 躲不躲得掉：電腦的子彈 ×0.55 很慢、一直橫移就閃掉；真正造成傷害的是全速的飛彈 / 火箭和瞬間命中的脈衝光束
  2. 盾牌：擋下的攻擊不會失衡；繞到沒盾的那一側打是決勝點（同一套機體 32–8 → 119–1）；盾 459 耐久是消耗品，破了就開始連續被火箭打到失衡
  3. 裝甲剋制影響整場：鏡面讓對方脈衝 ×0.65（承受從 ~490 降到 ~265）
  4. 脈衝照射中轉身 ×0.4 → 推進橫閃躲得掉（同機體對打 0–3/40 → 31–33/40）
- 對雜魚（各 10 場，難度 hard）：
  - 單一小隊（19 種）：alpha / beta 全部 100%，大多幾乎沒受傷（保持 12–19 格，雜魚的子彈飛不到）
  - 三個普通小隊一起（10–12 台）：100%
  - 精英小隊 ×2 + 重裝隊：alpha / beta 自己的機體只有 40%；但同一個大腦開突擊型 → alpha 100%、beta 80%（盾 + 單體脈衝怕被包圍，霰彈 / 火箭 / 範圍傷害適合打群）
  - 精英 ×3 + 砲車隊 + 重裝隊：0%
  - 對照：突擊型 + 內建 AI 對三小隊 10%、對精英包 0% → 大腦差距非常大

## 第二輪結果（個性機體）
主對話用另一個種子（3）獨立驗證雜魚關卡（5 組 × 10 場）：
| 機體 | 配裝重點 | 雜魚總計 | 精英包 |
|---|---|---|---|
| berserker 狂戰士 | 打樁拳 + 光束劍 + 雙火箭、全複合 | 98% | 9/10 |
| sniper 狙擊手 | 雙狙擊槍 + 雙直射飛彈 | 100% | 10/10 |
| artillery 重砲手 | 長距鎖定頭、垂直飛彈 + 燒夷彈、機砲 + 霰彈 | 92% | 7/10 |
| knight 騎士 | 騎槍 + 盾（主題允許）+ 直射飛彈、全陶瓷 | 84% | 4/10 |
| arsonist 縱火犯 | 雙火焰噴射器 + 燒夷彈 + 直射飛彈、全陶瓷 | 84% | 3/10 |
| missileer 飛彈指揮官 | 長距鎖定頭、垂直 + 直射飛彈、機槍 + 機砲 | 94% | 10/10 |
- 代理的心得：從整個 enemies[] 挑目標（先殺輸出高的，狂戰士對精英包 2/6 → 19/20）；裝甲照「實際被什麼打」選（雜魚的化學飛彈是大宗 → 陶瓷）；用 16 方向打分選移動（距離、被幾台看到、空間）取代單純風箏；利用雜魚 AI 自己會走到 6–10 格（騎士守株待兔）
- 一對一（代理的選配）：飛彈指揮官對狙擊手 20/20、對重砲手 19/20、對狂戰士 8/20；狂戰士、狙擊手對騎士 10–0；騎士、縱火犯對王牌機幾乎全輸（為打群設計）
- 發現：api.clearAhead 只看 0.8 倍機體半徑，騎槍衝刺會擦到轉角（beta 自己改用全寬檢查，自傷 ~50 → ~1）

## 第三輪：2v2 組合（完成）
- 基底：duel.mjs `--teamA x,y --teamB z,w`；大腦用 `act.target` 自己選目標（brainapi brainFoe；內建 AI 打最近的）；obs.allies[]
- alpha 做 a-* 機體 / 大腦 / tools/sim/teams/a-*.json，beta 做 b-*；可以用對方的六台個性機體、可以重訓成團隊版（新檔案，原本六台不動）
- 規則照舊：新機體單機雜魚關卡 ≥80%（兩個種子）、禁用脈衝、盾只給騎士主題
- 遊戲觀戰「AI 2v2…」：隨機配對 / 固定一隊打隨機對手（main.js TEAM_NAMES）
- 主對話循環賽（tools/sim/teamrr.mjs，種子 77，每組兩邊各 10 場、每隊 100 場）：
  1. 雙狼鉗形（b-berserker ×2）83%
  2. 獵犬與鷹（b-berserker + b-missileer）65%
  3. 交叉火網（a-artillery + a-missileer）54%
  4. 誘餌與伏擊（a-decoy + a-missileer）38%
  5. 護衛騎士（b-knight + b-missileer）30%
  6. 鐵鎚與鐵砧（a-knight + a-missileer）24%
- 兩個代理的共同結論：2v2 是飛彈 / 火箭的天下 → 陶瓷軀幹是最大的槓桿；光束劍（能量 ×1.4 打陶瓷）+ 火箭（52 > 雙足失衡門檻 50）的狂戰士是剋星；
  首殺大約 6–8 秒定勝負，節奏比站位重要；共用目標分數（集火）約 +10%，聰明的遠距目標選擇反而輸；有近戰對手時互相靠近（背靠背）、剩一台時兩邊包夾（交叉火網 10/40 → 22/40）
- 規則檢查：沒有脈衝；盾只在騎槍騎士（a-knight、a-guard、b-knight）上

### 已套用到遊戲（2026-11，使用者決定：敵我、玩家全部適用）
- 飛彈 / 火箭速度 ×0.8 改成所有人都適用（BAL.missileK = 0.8）；其他數值直接改在 WEAPONS（直射飛彈 轉向 1.6 / 48 發、垂直飛彈 1.55 / 64 發、火箭 48、騎槍點火 0.15 / 能量 35）；BAL.clearAheadK = 1
- 套用後雜魚關卡（4 個種子）：騎士 43/46/41/42 → 86%、縱火犯 45/44/41/44 → 87%、重砲手 47/41/?/47 → 約 90%
- 發現：同一套機制，亂數序列不同（粒子特效也吃 Math.random）單一種子就能差 12 個百分點（騎士 94% vs 82%）→ 比較時至少跑 3–4 個種子

### 平衡後重調 AI（完成）
- beta：knight / b-knight 讀武器本身的能量（35）、點火預判 0.15 秒 → 雜魚 4 種子平均 90.0% → 92.5%；missileer 直射飛彈改看鎖定目標的視線、彈藥低於 3 成時看不到就不打（省彈）→ 90.5% → 89.5%（雜訊內）
- alpha：a-knight / a-guard 能量 35、預判 0.15 / 0.2 秒 → 86.7% → 92.5%；berserker 火箭飛行時間用 ×0.8 的速度 → 98.7% → 96%
- 飛彈彈藥：2v2 兩隊都會打光（垂直約 28 秒、直射 35–42 秒），但加「省彈」反而輸（首殺決勝、彈藥兩邊一起耗）→ 不加
- 2v2 循環賽（種子 77）：雙狼 72%、獵犬與鷹 52%、交叉火網 49%、護衛騎士 47%、誘餌與伏擊 40%、鐵鎚與鐵砧 31%（改前 83 / 65 / 54 / 30 / 38 / 24 → 差距縮小）
