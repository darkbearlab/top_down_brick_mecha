# artillery 重砲手 筆記

主題：間接 / 重火力。範圍封鎖、轟敵群、跟敵人之間隔著東西。禁用脈衝 / 盾。
共用工具：src/brains/lib-alpha.js

## 第 1 輪：配裝 + 大腦 v1
- 配裝候選：長距鎖定頭（34 格、隔牆也鎖得到）/ 重裝軀幹 / 左垂直飛彈 / 右燒夷彈 / 左手機砲 / 右手霰彈（自衛）/ 全複合
  - 背部只有兩格：垂直飛彈（96 發，主力、越過牆打）+ 燒夷彈（封路 / 轟敵群）；加農砲只有 8 發、要直線射線，跟「躲在牆後」衝突 → 沒帶
- 大腦 v1：
  - 燒夷彈落點：照 0.75 秒後的位置，找 2.6 格內敵人最多的點（蟲 ×1.5、已經在燒的地方 −1.5）→「燒夷彈轟敵群」；
    近戰類（蟲 / 劍 / 霰彈 / 衝鋒）5–13 格衝過來而且沒有好的群 → 丟在我跟牠中間偏牠那邊「燒夷封路」
  - 平常兩邊都架背部；最近的敵人 8 格內看得到 → 燒夷那側換手臂（霰彈）「近身自衛」（但有群 / 要封路還是丟燒夷）；5 格內兩邊都換手臂
  - 移動：16 方向評分 = 跟最近敵人保持 16 格、在鎖定距離內、危險低、**看不到我的敵人比例越高越好（掩體）**、四周有空間
    → 意圖：隔牆砲擊 / 砲擊陣地 / 後撤 / 推進到射程
  - 近戰類 5 格內 → 推進脫離；閃重彈 / 落點 / 衝鋒機
- 腳（各 6 場，seed 1）：**履帶 21/30 = 70%**（突擊包 1/6、精英包 2/6：太慢被貼、近戰包圍）、**雙足 30/30**
- 選定雙足（重量 41 / 42）。gauntlet seed 1（各 10 場）：**47/50 = 94%**（突擊包 9/10、精英包 8/10）
  - 輸出（精英包）：垂直飛彈 ~55–80%、燒夷彈 ~20%、手臂自衛 0–25%
  - 意圖紀錄（突擊包一場）：燒夷彈轟敵群、後撤、近身自衛、燒夷封路、隔牆砲擊、垂直飛彈齊射、推進脫離
- gauntlet seed 2（全複合）：44/50 = 88%（突擊 8/10、精英 6/10）；輸了的場大多被精英飛彈兵的直射飛彈打死（化學打複合 ×1.4）

## 第 2 輪：裝甲
- 精英包 / 突擊包（seed 5、各 20 場）：全複合 14 / 17、全陶瓷 17 / 17、**軀幹陶瓷其他複合 18 / 18**、軀幹 + 腳陶瓷 20 / 15
  - 站遠距離 → 吃到的多半是飛彈（化學）；軀幹陶瓷擋飛彈，手 / 頭 / 腳複合擋機槍
- 配裝 v2：長距鎖定頭 / 重裝軀幹 / 雙足 / 左手機砲 / 右手霰彈 / 左垂直飛彈 / 右燒夷彈；軀幹陶瓷、其他複合
- gauntlet：seed 1 **48/50 = 96%**（精英 9/10）、seed 2 **48/50 = 96%**（精英 8/10）
- vs 突擊型（sample，各 10 場）：v1 7-3 / 換邊 8-2 → v2 3-7 / 換邊 7-3（突擊型是動能為主，陶瓷軀幹吃虧；不是硬門檻，雜魚優先）
- vs beta knight（當下版本）：4-6、換邊 3-7（騎槍衝刺貼上來，重砲手最怕這種）
