# alpha 筆記

## 第 0 輪：摸底（sample 大腦、各種配裝 vs 8 台預設機（sample 大腦）、兩邊各 5 場）
| 配裝 | 戰績 /80 |
|---|---|
| 雙脈衝 + 火箭 | 30-40 |
| 霰彈 + 機砲 + 雙火箭 | 64-6 |
| 脈衝 + 機砲 + 火箭 | 48-22 |
| 雙光束劍 + 火箭（逆關節） | 62-18 |
- 結論：火箭莢艙（3 × 52、化學、每發讓雙足失衡、不用鎖定）是最強的爆發；兩門火箭 = 一輪 312 原始傷害

## 第 1 輪：alpha 大腦 v1 + 雙火箭機
- 配裝：標準頭 / 標準軀幹 / 雙足、左霰彈、右機砲、雙背火箭；軀幹 + 手臂陶瓷（化學 ×0.65，防對方火箭 / 飛彈），頭腳複合
- 大腦：
  - 火箭只在打得到時打：距離 < 8、對方失衡 / 騎槍點火 / 打樁蓄力 / 推進中、或飛行時間短且對方慢
  - 預判照火箭的加速度算飛行時間；對方失衡就直接瞄現在的位置
  - 站 7.5 格繞圈，隨機換方向；近戰型對手站在它射程外 2.5 格
  - 重彈 / 飛彈 / 火箭 0.45 秒內打到就垂直推進；騎槍點火正對著我就橫移
  - 看不到敵人：16 個方向找「走幾步就看得到」的方向（v0 直接往敵人走會卡在中間建築 → 120 秒平手）
- 結果：vs 突擊 / 狙擊 / 打樁 / 騎槍 / 重砲（sample）48-3 /60；修好繞建築後 vs 突擊、雙火箭機（sample）20-0
