# alpha 筆記

## 第 0 輪：摸底（sample 大腦、各種配裝 vs 8 台預設機（sample 大腦）、兩邊各 5 場）
| 配裝 | 戰績 /80 |
|---|---|
| 雙脈衝 + 火箭 | 30-40 |
| 霰彈 + 機砲 + 雙火箭 | 64-6 |
| 脈衝 + 機砲 + 火箭 | 48-22 |
| 雙光束劍 + 火箭（逆關節） | 62-18 |
- 結論：火箭莢艙（3 × 52、化學、每發讓雙足失衡、不用鎖定）是最強的爆發；兩門火箭 = 一輪 312 原始傷害

## 第 1 輪：alpha 大腦 v1 + 雙火箭機
- 配裝：標準頭 / 標準軀幹 / 雙足、左霰彈、右機砲、雙背火箭；軀幹 + 手臂陶瓷（化學 ×0.65，防對方火箭 / 飛彈），頭腳複合
- 大腦：
  - 火箭只在打得到時打：距離 < 8、對方失衡 / 騎槍點火 / 打樁蓄力 / 推進中、或飛行時間短且對方慢
  - 預判照火箭的加速度算飛行時間；對方失衡就直接瞄現在的位置
  - 站 7.5 格繞圈，隨機換方向；近戰型對手站在它射程外 2.5 格
  - 重彈 / 飛彈 / 火箭 0.45 秒內打到就垂直推進；騎槍點火正對著我就橫移
  - 看不到敵人：16 個方向找「走幾步就看得到」的方向（v0 直接往敵人走會卡在中間建築 → 120 秒平手）
- 結果：vs 突擊 / 狙擊 / 打樁 / 騎槍 / 重砲（sample）48-3 /60；修好繞建築後 vs 突擊、雙火箭機（sample）20-0

## 第 2 輪：換配裝（雙火箭 + 脈衝 + 重裝）、大腦 v3
- 自己打自己（alpha 大腦、兩邊各 5 場）找配裝：
  - 履帶 2-8（太慢）、全複合 0-10（吃火箭 ×1.4）、全陶瓷 8-2、重裝軀幹 7-3、脈衝取代霰彈 7-3 / 9-1（霰彈幾乎沒打過：距離大多 8–14）
  - 重裝軀幹 + 脈衝 + 機砲 + 雙火箭 + 全陶瓷（c3）勝過上面幾種
- 試過但變差：一邊火箭、一邊手臂不停打（1-19，雙火箭一輪 6 發的爆發才是重點）
- 大腦 v3：看對方彈藥數變化推算對方重武器的冷卻；對方火箭在冷卻 → 衝近、準備好 → 中距離等。對自己 7-13（跟 v1 差不多，雜訊大）
- beta 換成「重裝 / 雙足 / 左盾 / 右脈衝 / 雙直射飛彈 / 全陶瓷」：c3 只剩 5–8 /20
  - 戰鬥紀錄：我脈衝只打 3–7 次（同一邊火箭架著，脈衝要等火箭打完）；被飛彈打 700–950
- 試「站 19 格外（飛彈射程 / 鎖定 18）只用脈衝」：失敗 3-17。場地有限，對方一直靠近，距離大多還是 8–14
- 試盾牌配裝（f1 = 跟 beta 一樣的機體）：3-17 → 同一台機體 beta 大腦好很多。看紀錄：
  - beta 一次都不推進（盾吃飛彈）、脈衝 11–12 發、命中 80% tick；我推進 6–7 次（能量見底 10 秒）、脈衝 9 發、命中 40–70%
- 修正（大腦 v3.1）：
  - **有脈衝時能量 = 傷害**：一般飛彈打陶瓷只有 ~20，不值得花 30 能量閃（能量 > 85 才閃）；追蹤飛彈要等 tti < 0.22 才閃（太早閃它會轉回來）
  - 自己的盾擋得到的方向不閃
  - 脈衝瞄現在位置（不預判）、對準 0.07 才開、能量留 20 預備
  - 飛彈要鎖定（或 9 格內）才打
- 結果 vs beta（兩邊各 10 場）：c3 15-5、f1（盾 + 脈衝 + 雙飛彈）16-4、f5（盾 + 脈衝 + 單火箭）9-11

## 第 3 輪：換成盾 + 脈衝機、大腦會繞到對方沒盾的那一側
- beta 大腦一直在變（它也會暫時改 beta.js 做 A/B），所以把 beta 當下的版本複製一份（out/alpha/b/beta1.mjs + beta1.json）固定拿來比
- beta v3：站在「我的威脅距離 + 8」≈ 17.5 格風箏（剛好在我火箭條件外）、脈衝 + 雙飛彈 + 盾
- 配裝 vs beta1（兩邊各 20 場）：c3（雙火箭）18-22、c3c（雙脈衝雙火箭）16-24、h1（雙脈衝雙飛彈）9-31、h2（雙脈衝單火箭）16-24、**g1（跟 beta 一樣：多重鎖定頭 / 重裝 / 雙足 / 盾 / 脈衝 / 雙飛彈 / 全陶瓷）31-9**
  - 重點：對全陶瓷的對手，**脈衝（能量 ×1.4、瞬間命中）一直能用**比火箭重要；火箭打陶瓷 ×0.65、打在盾上不會失衡
- 大腦 A/B（g1、vs beta1、各 40 場）：原本 32-8；脈衝對準 0.12 32-8；能量不留預備 27-13；完全不閃飛彈 29-11；
  **繞側（對方有盾 → 一直往它沒盾的那一側橫移）40-0、40-0、39-1** → 採用
  - 原理：盾在左前方偏 35°、擋 ±78°；從它右前方 43° 以外打過去就繞過盾。拿盾的重裝上半身只有 2.6 rad/s，照射脈衝時 ×0.4 → 跟不上
- 「對方盾擋著就收起火箭」（shieldAware）：c3 vs beta1 7-33（比不收 24-16 差很多）→ 關掉
- 選定：g1 + 繞側。gauntlet（8 台預設，各 10 場）75-5（打樁型 5-5 是弱點）
- 注意：alpha 大腦開 c3 打 alpha 大腦開 g1 → c3 25-5。如果 beta 改回雙火箭機，要再換回來

## 第 4 輪：架盾（guard）+ 對各種對手的穩健度
- beta2（新版 beta 大腦，同機體）：g1 + 繞側 39-1 /40
- 拿 beta 的大腦開各種機體打我（g1 + alpha）：c3 28-2、c3c 26-4、f1 30-0、h2 28-2、h3 30-0（都是我贏的場數 /30）
- 弱點：alpha 大腦開 c3（雙火箭）會繞我的盾、火箭讓我失衡 3–4 次 → g1 只贏 4–5 /30
- 加「架盾」：脈衝還沒好、沒在照射時，上半身往沒盾那側偏 guard 弧度，讓對方落在盾的中心（盾中心偏 35°）
  - vs c3(alpha) /30：guard 0 → 4、0.3 → 7、0.45 → 6、0.6 → 9；vs beta2：29 / 27 / 30 / 29 → 用 0.45
  - 之後 g1 vs c3（都用現在的大腦）8-12、c3 vs g1 12-8：差不多打平
- 其他盾配裝（盾 + 脈衝 + 火箭 / 飛彈混搭 k1–k3）都比 g1 差
- gauntlet（g1、guard 前）：sample 大腦 77-3 /80、內建 AI 80-0 /80
