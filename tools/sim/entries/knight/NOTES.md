# knight 騎士 筆記（beta 個性機體 1）

主題：衝擊騎槍為核心，挑一個對手、點火、整台衝過去撞。盾牌只在這台允許（騎槍 + 盾），但不能變成盾牌風箏機。
門檻：雜魚關卡 `gauntlet.mjs --entry knight --n 10` 總勝率 ≥ 80%（兩個種子）。

## 第 1 輪：初版（逼近 → 點火 → 回馬）
- 配裝：標準頭 / 重裝軀幹 / 雙足 / 左盾 / 右騎槍 / 左背直射飛彈（盾那側永遠架著）/ 右背空；全複合
  - 重裝軀幹手臂負重 13 才放得下騎槍 6 + 盾 6
- 大腦：挑對手（距離、血少、路線沒牆、旁邊敵人少）→ 斜著逼近到 5.5 格 → 對準就點火；撞完回馬（盾朝敵群往空曠處退）
- 結果：39/50 = 78%（精英包 3/10）。傷害：飛彈 > 騎槍；騎槍手被飛彈打掉後就只能挨打
- 發現：騎槍命中後直接停下（lanceHit 撞到第一台就停）、傷害 ≈ 136（迎面撞 150–210）、雜魚大多一擊斃命

## 第 2 輪：守關（掩體邊等人上門）+ 路線檢查
- 讀 ai.js：雜魚射擊型 want = 8 → 自己會走到 6–10 格；所以騎士不用追，在掩體邊等，誰走進槍尖距離就衝誰
- 改：
  - 狀態：對準（槍尖距離內有路線通的 → 挑分數最高的、一邊橫移一邊對準）/ 守在掩體（16 方向 × 0、2.5、5 格找「少數遠程敵人看得到」的點）/ 回馬 / 前進（等 4 秒沒人上門）
  - 挑戰分數：帶飛彈的 +2（傷害最大來源）、10 格內的近戰 +2（迎面撞更痛）、旁邊每多一台 −1、要轉多少
  - 點火中：只轉向路線通的方向（衝刺方向 = 點火結束時的上半身方向）
  - **路線檢查改成機體全寬**（中心 + 兩側 1.1 倍半徑的射線，滿 8.2 格）：api.clearAhead 只看 0.8 倍半徑會擦到牆角 → 自傷 50/場 → 1/場
  - 等待 / 對準時橫移（電腦子彈慢）：精英包 0→1/16、突擊包 8→10/16（雜訊大）
  - 試過：雙騎槍（沒盾）→ 盾那側不能架飛彈、更差；履帶（不會失衡）更差；裝甲各種組合差不多（雜訊內）
- 配裝：頭陶瓷、軀幹複合、手臂陶瓷（騎槍手常被飛彈打掉）、腳陶瓷
- 結果：39/50 = 78%（突擊 8、狙擊 10、蟲 10、衝鋒 10、精英 1）
- 精英包承受（16 場平均）：飛彈 275、機槍 195、劍 113、霰彈 72、機砲 48

## 第 3 輪：撞完推進脫離、全陶瓷 → 過門檻
- 參數掃描（精英包各 24–32 場、不同種子）：COVER / ADV / MSL / MEL / CROWD_PEN / STRAFE 全部在雜訊內（精英包 4–12 /32 看種子）→ 參數不是關鍵
- 改：
  - 撞完（衝刺結束 0.5 秒內）5 格內還有敵人 → 往遠離敵群的方向推進脫離（撞完能量 55 → 25，騎槍冷卻 2 秒內能量就回到 45，不影響下一槍）
  - 盾朝飛彈兵（SHM）：精英 6 vs 12 /20 → 不用（留參數 0）
  - 「挑戰：<射手 / 近戰 / 衝鋒機 / 自爆機>」只在騎槍準備好時記（之前每次換目標都記，紀錄很吵）
- **裝甲：全陶瓷**（同大腦、兩個種子、各包 20 場平行跑）：軀幹複合 79% / 78% → 全陶瓷 92% / 85%
  - 雜魚傷害最大來源是精英飛彈兵的飛彈（化學）：陶瓷 ×0.65、複合 ×1.4
- 結果（gauntlet --n 10）：種子 1 **47/50 = 94%**（精英 7/10）、種子 2 **45/50 = 90%**（精英 6/10）
  - 擊殺數：騎槍 255、飛彈 162（騎槍約 6 成；傷害量 46%，因為騎槍常常一擊就死、溢出不算）
- vs 突擊型（sample 大腦）：A 邊 6/10、B 邊 6/10 → 12/20
- 測試用的 KT 環境變數拿掉（參數在檔案開頭的 T 表）

## 第 4 輪：平衡調整後（4d2353a：點火 0.15、騎槍能量 35、clearAhead 全寬）重調（beta）
- 改：騎槍能量門檻改讀武器的 energy（現在 35，原本寫死 45）；點火預測 T.IGN = 0.15（原本寫死 0.3 / 0.35）；閃避預留能量變成參數 T.RES = 30
- 掃描（gauntlet 種子 1–4、各 10 場）：ALIGN 0.07 / 0.10 × RES 30 / 15 → 92.0–92.5%，都在雜訊內 → 維持 0.07 / 30
- 自己的全寬路線檢查（lane）現在跟 clearAhead 重複，但不衝突，留著
- gauntlet 種子 1–4：調整前 86 / 90 / 90 / 94 = **90.0%** → 調整後 88 / 92 / 92 / 98 = **92.5%**（沒有低於 80% 的種子）；b-knight 單打一樣
