# a-artillery 團隊版重砲手 筆記（alpha 2v2）

從 artillery 複製。配裝改：**全陶瓷**（2v2 的對手幾乎都是化學飛彈；原版頭 / 手 / 腳複合 = 化學 ×1.4，頭和背部最先被打壞）。
大腦 `src/brains/a-artillery.js`；`lib-a-team.js`。沒隊友時團隊邏輯全關。
隊伍：`tools/sim/teams/a-crossfire.json`（交叉火網，+ a-missileer）

## 第 1 輪：集火 + 交叉火網 + 燒夷掩護
- 集火目標 → act.target，垂直飛彈鎖它；燒夷彈：貼近隊友（6 格內）的敵人 → 丟在牠腳下「燒夷掩護」
- 一開始就拉夾角 → vs 原版 artillery+missileer 8/40（離開掩體被兩台看到）；關掉夾角 13/40；全關 16/40
## 第 2 輪：包夾收尾（夾角只在只剩一台敵人時用）
- 只剩一台敵人：距離 16 → 10、掩體分數反過來（要看得到）、跟隊友拉夾角「包夾」
- 看紀錄：先殺掉一台後 2v1 打不死對面躲牆的飛彈機、拖到時間到 → 包夾就是為了這個
- vs 獵犬與鷹：10/40 → 22/40（同種子 11）
- 全陶瓷：gauntlet 種子 1 47/50 = 94%
