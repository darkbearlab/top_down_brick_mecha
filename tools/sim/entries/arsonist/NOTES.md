# arsonist 縱火犯 筆記（beta 個性機體 2）

主題：火焰噴射器 + 燒夷彈。把地面點著、燒腳讓敵人變慢、把敵群趕進火海。禁用脈衝、盾牌。
門檻：雜魚關卡 `gauntlet.mjs --entry arsonist --n 10` 總勝率 ≥ 80%（兩個種子）。

## 第 1 輪：初版
- 配裝：標準頭 / 重裝軀幹 / 雙足 / 雙火焰噴射器 / 雙燒夷彈；全陶瓷（重 37 / 42）
- 大腦：
  - 噴火方向：每台 8 格內敵人的方向當候選，數 ±0.38 弧度扇形、5.6 格內有幾台 → 挑燒到最多台的（近戰 +0.5）
  - 燒夷彈落點：0.75 秒後的預測位置，半徑 2.6 內最多台的點；已經在燒的地方扣分；近戰追兵加分（火牆）
  - 最近的敵人 > 7.5 格 → 兩邊架燒夷彈丟；近了 → 換回噴火器、繞著目標 4.2 格外圈噴
  - 5 格內 ≥ 3 台或被包圍 → 後退引火（往遠離敵群的方向退）
- 結果（各包 10 場）：78%（突擊 6、精英 3）。燒夷彈幾乎沒用到（只有開場丟一次），傷害幾乎都是噴火器

## 第 2 輪：連小飛彈也閃、右背火牆
- 參數（想站的距離、被圍門檻、燒夷彈門檻）都在雜訊內
- **小飛彈也閃（dodge light）**：縱火犯不用能量開火，推進能量很多 → 雜魚的直射飛彈在 0.45 秒內要打到就橫推進
  - 突擊包 13 → 18 /20、精英 3 → 9 /20（跟之前「飛彈躲不掉」的心得相反：電腦飛彈轉向 1.9 rad/s，最後一刻橫推進甩得掉）
  - 各包 20 場：種子 1 87%、種子 2 88%
- 燒夷彈落點 = aimAt，跟上半身方向無關 → 可以左手往前噴、右背往旁邊丟
  - 右背燒夷彈（SIDE）：1 = 火牆 + 旁邊的敵群、2 = 只丟火牆（被逼近時丟在自己和追兵之間 3.6–5 格）、3 = 只丟敵群
  - 一開始任何時候都換：79%（換武器 0.3 秒、右手噴火器停掉）；改成只在噴火器沒東西燒的時候換（IDLE）：SIDE 1 84%、SIDE 2 88% → 用 2
  - 燒夷彈現在每場約 8 發（之前 1 發）
- 正式 gauntlet：種子 1 42/50 = 84%、種子 2 39/50 = 78%（精英 2/10）→ 還不穩
- 試過：履帶（不失衡）rush 14 elite 2 /20 更差；軀幹 / 手臂複合：雜訊內；遠近切換加遲滯、小飛彈要留能量才閃：雜訊內
- 精英包承受（10 場平均）：機槍 308、劍 210（能量打陶瓷 ×1.4）、飛彈 154、機砲 108、霰彈 81

## 第 3 輪：近戰貼身推進拉開、左背換直射飛彈 → 過門檻
- 為了穩定比較，改成「突擊包 + 精英包、種子 5 / 6 各 25 場」（另外三包一直 100%）
- 近戰（劍兵）貼到 3 格內 → 往後推進拉開（一邊退一邊噴，追過來的一直在扇形裡）：短測 精英 6 → 15 /24，大樣本 26 vs 27 /50 → 雜訊內，但留著（行為上合理、意圖「拉開」）
- 撲上去（推進撲向噴火距離外的射手）：rush 40 → 30–34、elite 26 → 21 /50 → 拿掉
  - 原因（讀 ai.js）：射擊型雜魚的射擊位置在 6–9.6 格（want 8），**一被打到就重挑位置** → 被燒就往外跑，撲上去也追不到，反而推進用光沒能量閃
- **左背換直射飛彈（輔助）**：噴火器沒東西燒、最近的在噴火距離外 → 架左背飛彈打站在外圈的射手；右背留燒夷彈（遠的時候丟敵群、近的時候丟火牆）
  - rush 40 → **50/50**、elite 26 → 23 /50；各包 20 場：種子 1 90%、種子 2 88%
- 配裝：標準頭 / 重裝 / 雙足 / 雙火焰噴射器 / 左背直射飛彈 / 右背燒夷彈；全陶瓷（重 37 / 42）
- 結果（gauntlet --n 10）：種子 1 **43/50 = 86%**（精英 4/10）、種子 2 **46/50 = 92%**（精英 6/10）
  - 擊殺（種子 2、50 場）：燃燒 154 + 噴火器 121 + 燒夷彈 9 = **火 284**、飛彈 141 → 三分之二是燒死的
- vs 突擊型（sample 大腦）：A 邊 5/10、B 邊 8/10 → 13/20
