# b-fuel 油龍 筆記（beta：汽油投射器機體）

主題：雙汽油投射器。不走「汽油 + 機砲 + 燒夷彈」的放風箏，而是兩把火舌當主武器、站在 6–9 格（雜魚火焰噴射器 6 格外、射擊型想站的 8 格正好在火舌裡），背部只在射程內沒東西燒的時候架起來。禁用脈衝、沒有盾。

## 配裝
標準頭 / 標準軀幹（轉速 5，甩火舌）/ 雙足 / 雙汽油投射器 / 左背直射飛彈 / 右背火箭莢艙；全陶瓷（手臂負重 10/10、背部 12/14、總重 34/42）

## 大腦（src/brains/b-fuel.js）
- 目標：射程內看得到的敵人打分（近的、自爆機、近戰、快死的加分；角度差大的扣分）
- 「輪流點火」：每台燒 0.55 秒就換下一台、2 秒內燒過的扣分（燃燒每部位最多 5 層、3 秒）→ 換目標時火舌甩出弧線，沒打到的燃料落在 10 格變油灘
- 預判：燃料水平速度 24（不吃電腦子彈 ×0.55）
- 距離：一般 7.6 格、有近戰 / 衝鋒機 / 自爆機在 8 格內 → 退到 6.2 格倒退噴；被圍 → 後退；劍兵貼 3.2 格內 → 推進拉開；閃用 lib-beta dodge（連小飛彈也閃）
- 射程內沒東西 → 兩邊背部（飛彈 / 火箭）一起架起來
- 控制組：手臂換成火焰噴射器 / 機砲也會開火（比較武器用）；`B_FUEL_T` 環境變數可以覆寫參數（只在 node）

## 平衡提案（tools/sim/patches/fuel-b.mjs）
`dmg 2.4 → 2.0、puddleBurn 1.1 → 1.4、puddleMax 1.5 → 1.8`：強度從單體直傷挪到地上的火
- gauntlet：92.5% → 90.5%（46 / 46 / 44 / 45）；1v1 合計 200 → 179（berserker 50、knight 51、missileer 2、sniper 50、artillery 26）
- 內建 AI 的汽油型：24% → 24%（內建 AI 只點放，數值救不了，要改 ai.js）
- 其他試過的：只降直傷（2.0 / 1.8+burn 0.18）gauntlet −4–6 點、1v1 幾乎不變；射程 8.5：1v1 也幾乎不變（大腦距離要跟著改，不然站進火焰噴射器 6 格內）
