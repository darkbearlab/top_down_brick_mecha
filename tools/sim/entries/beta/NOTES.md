# beta 筆記

## 第 0 輪：摸底（sample / beta v1 大腦 vs 8 台預設機，兩邊各 5 場）
- 雙霰彈雙火箭 / 突擊型類（霰彈 + 機砲 + 雙火箭）62/80 左右；履帶重裝 58；雙脈衝懸浮 13–31（很爛）
- 發現：
  - 電腦的「子彈」只有 0.55 倍速（狙擊 0.5），但**火箭 / 飛彈是全速**、飛彈還會追蹤 → 子彈靠橫移躲得掉，火箭 / 飛彈躲不掉
  - api.leadYaw 一律用 0.55 倍速算 → 拿來瞄火箭會瞄錯（自己算火箭飛行時間）
  - 盾牌（guard 340×1.35 = 459、裝甲照手臂）擋下的直擊**不會造成失衡**（hitMech 在盾那裡就 return）；從盾那側前方 ±78°（偏向盾那側 35°）來的都擋
  - 兩台都往對方直走會卡在柱子兩邊 120 秒平手 → 看不到時要找「走幾步就看得到」的方向

## 第 1 輪：beta 大腦 v2（風箏）+ 盾牌風箏機
- 對手 alpha：標準 / 雙足、霰彈 + 機砲 + 雙火箭，軀幹手臂陶瓷；大腦只在打得到時打火箭（8 格內 / 對方失衡 / 推進中）
- 一開始拿同類（火箭近戰）跟它打：0–3 /20（它的火箭時機比我好）
- 大腦 v2：
  - 有飛彈 / 脈衝 → 站在「對手威脅距離 + 3」（對火箭機 ≈ 12 格）繞圈；退路被擋就改大幅橫移
  - 火箭按物理算飛行時間瞄準；飛彈有鎖定才打；脈衝要對準 + 留能量
  - 重彈 / 火箭 / 騎槍點火真的要打到才橫推進（少推進：alpha 會趁對方推進打火箭）
  - 看不到：16 方向找看得到的位置
- 配裝試驗（vs alpha，兩邊合計）：
  | 配裝 | 戰績 |
  |---|---|
  | 懸浮、脈衝 + 機槍、雙飛彈、複合 | 1/20 |
  | 懸浮、雙脈衝 + 飛彈 | 7/20 |
  | 雙足、盾 + 霰彈 + 雙火箭 | 3/20 |
  | 懸浮、**盾 + 脈衝 + 雙飛彈**、軀幹手臂陶瓷 | 13/20、23/40 |
  | 同上、全陶瓷 | 30/40 |
  | 同上、全複合 | 5/40（對方火箭化學 ×1.4） |
  | 重裝軀幹 + 懸浮（超重）、全陶瓷 | 39/40 |
  | **重裝軀幹 + 雙足、全陶瓷** | **39/40** |
  | 重裝 + 履帶、全陶瓷 | 19/40（太慢） |
- 選定：**重裝軀幹 / 雙足 / 左盾 / 右脈衝 / 雙直射飛彈 / 全陶瓷**（重 40 / 42 不超重；雙足失衡門檻 50 → 飛彈 30 不會讓我失衡）
  - 盾擋正面的火箭 + 霰彈（不會失衡）、陶瓷吃化學 ×0.65、重裝軀幹 432 耐久；脈衝瞬間命中、能量打陶瓷 ×1.4，飛彈追蹤
- 耐打測試（vs 8 台預設，兩邊各 5 場）：sample 大腦 79/80、內建 AI 80/80

## 第 2 輪：盾擋得住就不閃、拉遠一點、廣角→多重鎖定頭
- alpha 換了大腦（追蹤對方彈藥、對方重武器冷卻時衝進來整輪打；也會用脈衝），配裝沒變
- 看紀錄：我輸的場 = 盾被打爆（盾 459 耐久，吃掉約 340 的火箭）之後火箭直擊軀幹正面、連續失衡；
  另外我常為了閃火箭推進 → 能量見底（打不了脈衝）、而且 alpha 看到對方推進就打火箭
- 大腦 v3：
  - 威脅如果是從盾擋得住的方向來（照 hitMech 的盾判定 + 餘裕）→ 不推進，讓盾吃（盾擋下的直擊不會失衡）
  - 風箏距離 = 對手威脅距離 + 5（原本 +3）。掃描 +1/+3/+5/+7（各 80 場）：71 / 74 / 75 / 74，承受傷害 +5、+7 最低
- 配裝：頭換多重鎖定頭（鎖定 0.55 秒、20 格；重量剛好 42/42）。同一版 alpha 各 80 場：標準頭 66、狙擊頭 68、多重鎖定頭 70
- 結果：vs alpha 75/80；預設機 sample 79/80、內建 AI 80/80

## 第 3 輪：A/B 測試（同一版 alpha、同種子，舊 / 新大腦一起跑）
- alpha 一直在改大腦（00:15、00:20、00:22 都有新版），所以改成「舊大腦放 scratch、跟新大腦同時跑」比較，不再拿不同時間的結果比
- 試了「脈衝優先（右手一直用脈衝，打不到才換飛彈）」：62/80 vs 原本（飛彈優先）70/80 → 退回。
  脈衝每發吃 28 能量，能量常常 < 30 → 剛好落入 alpha 的「對方不能閃 → 打火箭」條件；飛彈量大、逼 alpha 一直推進閃、把它的能量耗光
- 讀 alpha 大腦：它在「對方能量 < 30 或剛推進完（boostCd > 0.15）」而且火箭飛行時間 < 0.55 秒（約 17 格內）時打火箭
  → 風箏距離再拉遠：想站的距離 = 威脅距離 + 8、上限 19（對 alpha ≈ 17.5 格，剛好在它的火箭條件外；脈衝 20 格、多重鎖定頭 20 格還打得到）
  - 同種子 3 × 60 場：近（+5、上限 15）158/180、遠（+8、上限 19）166/180，承受傷害 430 → 316
  - 盾破了再拉更遠（+4）：沒差，不採用
- 結果：vs alpha 約 92%；預設機 sample 80/80、內建 AI 80/80

## 第 4 輪：alpha 抄了我的機體，鏡像對打被屌打 → 學會「閃光束」
- alpha 先換成重裝 + 脈衝 + 機砲 + 雙火箭（全陶瓷，脈衝打我陶瓷 ×1.4）→ 我掉到 ~60%
- 接著 alpha 直接抄我的配裝（盾 + 脈衝 + 雙飛彈），然後改成鏡面裝甲（m4：頭軀幹腳鏡面、手臂陶瓷）→ 我 0–3 /40（同機體，大腦輸）
- 查原因：
  - 不是射線（雖然發現：看得到但手臂槍口被柱子擋住的時間很多 → 加了「挪一步讓槍線通」）
  - 也不是距離 / 脈衝優先 / 繞側 / 能量保留（都試過，0–7 /40）
  - 讀 alpha 筆記：它靠「繞到對方沒盾的那一側」+ 架盾
  - **真正的關鍵：對方脈衝在充能 / 照射、光束線離我 < 3 格 → 立刻橫推進**（照射中對方上半身只剩 0.4 倍轉速，推進的角速度它追不上，整道 84 傷害就落空）
    - 只有盾擋不住時才閃：14–23 /40；**連盾擋得住也閃**（盾被脈衝打也是傷害，手臂陶瓷吃能量 ×1.4）：31–33 /40；觸發範圍 1.5 → 2.5–4 格再好一點
  - 其他：繞側（往對方沒盾那邊橫移）留著（小幅正面）；架盾（上半身偏 0.45）沒差 → 不開；脈衝優先反而大輸（6 /40）
- 裝甲重選（同一個 alpha 大腦開 4 種機體：m4 / 重裝雙火箭 alphaR / 一開始的 alpha0 / 我舊的全陶瓷 g1，各 30–40 場，兩次合計 /140）：
  全鏡面 173、**頭軀幹手臂鏡面 + 腳陶瓷 187**、手臂陶瓷其他鏡面 163、頭腳陶瓷 156、全陶瓷 ~130
  - 對手現在幾乎都是能量（脈衝）+ 化學（飛彈 / 火箭）；鏡面吃能量 ×0.65、化學 ×1
- 選定：多重鎖定頭 / 重裝 / 雙足 / 左盾 / 右脈衝 / 雙飛彈；**頭、軀幹、手臂鏡面，腳陶瓷**
- 結果（vs alpha 現在的版本 m4）：78/100；gauntlet sample 74/80（打樁型 7/10、鏡面吃動能）、內建 AI 80/80
- 弱點：alpha 大腦開重裝雙火箭（alphaR）只有 ~50%；alpha 大腦開我舊的全陶瓷 g1 我也只有 ~45%

## 第 5 輪：盾擋得住的火箭也要閃
- alpha 大腦開重裝雙火箭（alphaR：脈衝 + 機砲 + 雙火箭）我只剩 ~40%：統計 → 盾 8–15 秒就被火箭打爆（鏡面手臂吃化學 ×1），之後火箭連段失衡 3.4 次
- 改：火箭來了，就算盾擋得住也橫推進（盾的耐久比 30 能量值錢）。vs alphaR /50：28 → 44–45
- 順便試：對方有火箭架著就不閃光束（怕推進後被火箭補）→ 沒差、不採用；履帶（不會失衡）→ 很爛（m4 10/40、alphaR 0–1/40）
- 裝甲再比一次（alpha 大腦開 4 種機體，兩個種子合計 /320）：頭軀幹手臂鏡面 + 腳陶瓷 227、全鏡面 230、頭軀幹鏡面 + 手腳陶瓷 218 → 留現在的
- 結果：vs alpha 現版（m4）83/100；gauntlet sample 75/80

## 第 6 輪：收尾（整理大腦、最終成績）
- 大腦把測試用的環境變數拿掉，參數收成檔案開頭的 T 表（同種子結果完全一樣）；沒用到的分支（脈衝優先、架盾、盾破拉遠…）刪掉
- 最終配裝：多重鎖定頭 / 重裝軀幹 / 雙足 / 左盾 / 右脈衝 / 雙直射飛彈；頭、軀幹、手臂鏡面，腳陶瓷（重 42 / 42）
- 最終成績
  - vs alpha 最新版（m4：同樣的盾 + 脈衝 + 雙飛彈、鏡面）：兩個種子、兩邊各 30 場 → **90 / 120（75%）**
  - gauntlet：8 台預設 × sample 大腦（兩邊各 10 場）148 / 160；內建 AI 80 / 80
  - alpha 大腦開其他機體（各 40 場）：重裝雙火箭 alphaR 約 28–33、初版霰彈雙火箭 36–38、全陶瓷舊版的我 17–24
- 心得
  1. 「躲不躲得掉」決定一切：子彈 0.55 倍速可以靠橫移躲，火箭 / 飛彈全速、脈衝瞬間 → 傷害幾乎都來自這三種
  2. 盾擋下的直擊不會失衡，而且一面盾 = 459 耐久；但盾是會用完的資源：盾擋得住的火箭也要閃，盾撐越久越贏
  3. 脈衝光束照射中轉得很慢 → 對方開始照射就橫推進，整道 84 傷害落空；這一招讓鏡像對打從 0–3/40 變成 31–33/40
  4. 剋制倍率要看對手現在的武器：對手全是能量 + 化學 → 鏡面最划算；對手有動能（機砲 / 霰彈 / 打樁）鏡面會吃虧（gauntlet 打樁型、狙擊型掉場）
