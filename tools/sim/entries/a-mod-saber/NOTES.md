## 第 2 輪：供能模組加推進 ×0.75、回能 ×1.3（commit 01e8eee）
- gauntlet 種子 1–4：49 / 48 / 49 / 50 = 98%
- 正面對決 vs 雙火箭對照（兩邊、種子 1–3、各 20）：24% → 30%
- patch 試：推進 0.6 + 回能 1.5 → 37%；現值 + 光束劍 ×1.3 → 34%；推進 0.6 + 回能 1.5 + 光束劍 ×1.3 → 41%
- 「空背槽白拿模組」檢查：b-mod-knight 94.5%（47 / 48 / 47 / 47）vs 原版 knight 93%（44 / 47 / 46 / 49）→ 不是必帶
- 結論：火箭莢艙的爆發還是比較值錢；最接近 50% 的是推進 0.6 / 回能 1.5 / 光束劍 ×1.3（41%）

## 第 3 輪：會用模組的大腦（src/brains/a-mod-saber.js 改成 berserker 的完整複本 + 模組判斷）
- 偵測：背部有 kind 'module'、id 'power'、沒壞 → 推進 22.5、一刀 10.5 照便宜的算；沒模組 = 原版門檻
- 突進門檻 45 → 推進 + 一刀 + 2（≈ 35）、距離 11 → 14；閃的門檻 = 一次推進；有模組連追蹤飛彈也閃
- 「砍完繞側」（劍冷卻中側推進）：開 31% / 關 36% → 預設關（A_SIDE）
- 正面對決 vs 雙火箭對照（同一顆大腦；對照沒模組 = 原版行為）：30% → 36%
  - 看紀錄：鏡像近戰 12 秒就打完、能量見底只有 ~1 秒 → 省能量用不上，火箭 400+ 的爆發決定勝負
- 對共同對手（兩邊、種子 1–3、各 20）：vs missileer 模組 54% / 火箭 39%；vs knight 模組 66% / 火箭 84%
  → 長的、追著跑的仗（飛彈機風箏）模組比較好；短的正面硬碰（騎士、鏡像）火箭比較好 = 情境選擇
- gauntlet 種子 1–4：50 / 49 / 49 / 50 = 99%；1v1 vs 突擊型（兩邊、種子 1–3）99%
