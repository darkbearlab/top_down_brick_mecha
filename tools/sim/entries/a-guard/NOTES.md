# a-guard 護衛騎士 筆記（alpha 2v2）

配裝 = a-knight；大腦 `src/brains/a-guard.js` = `makeKnight({ LEASH: 6, GUARD: 1.0, FOCUS: 1.0 })`：守點緊貼隊友、優先撞貼近隊友的敵人。

## 第 2 輪：盾衛砲台（+ a-artillery）
- 原版 knight+artillery vs knight+missileer 只有 2/40；a-guard+a-artillery 9–10/40；vs 獵犬與鷹 5/40
- 結論：重砲手（垂直飛彈 + 燒夷彈）的輸出撐不起隊伍，騎士貼身也救不了 → 這組不當正式隊伍（隊伍檔已刪）
