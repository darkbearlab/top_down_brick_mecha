# a-fuel 油龍（alpha）— 汽油投射器

## 配裝
標準感測頭、重裝軀幹、雙足、全陶瓷；左手汽油投射器、右手機砲、左背直射飛彈、右背燒夷彈
- 陶瓷：雜魚的大宗是化學飛彈 / 火箭（跟其他個性機體同樣的理由）
- 機砲：10 格外的輸出、單挑時的主力（兩隻手同一個上半身方向，跟著油槍的方向打）
- 飛彈：油槍打不到（> 10.8 格、沒有目標）才把左邊換成飛彈；燒夷彈：遠處 2 台以上擠在一起、或衝過來的近戰前面
- 沒有盾（主題不需要）、沒有脈衝

## 大腦（src/brains/a-fuel.js）
- 掃：自己估計每台的燃燒層數（瞄著、它是射線上第一台 → 每秒 +3.4 層、每秒退 1.2），快滿（4.2）就甩到下一台；
  選目標分數 = 威脅 + 沒燒滿 + 近戰 / 自爆加分 − 要甩多大角度；甩過去途中照噴（al < 0.9），整條火舌掃過中間的
- 距離：最近的敵人 8 格（近戰 8.5）；16 方向打分（距離、dangerAt、目標還在 10 格內且看得到、敵人的火海、空間、橫移）
- 自爆 / 劍兵貼上來 → 推進拉開；重彈 / 飛彈 → lib-alpha dodge
- 火牆只對雜魚 / 多台 / 劍類：單挑時右邊一直換燒夷彈 = 機砲停火（對火焰型鏡像 4/40 → 35/40）
- 同一個大腦也能開火焰噴射器（對照用：距離 4.5、射程 5.8）

## 其他發現
- 燃燒傷害（att(null, 'burn')）沒有記到武器上 → 報告的「輸出」少算了汽油 / 火焰 / 燒夷彈（單挑每場約 240–280）
- 電腦的子彈 ×0.55，但汽油燃料沒有減速（24）→ 模擬裡它比機砲（17.6）準；玩家那邊機砲 32 > 燃料 24，玩家拿它單挑會比模擬弱
- 把距離拉近（5.5 / 6.5）反而更差（鏡像 vs 機砲 6、10/40）；機砲預判靠向子彈速度也沒有比較好
