# berserker 狂戰士 筆記

主題：近戰。衝進去、臉貼臉打、挑砍得死的獵物。禁用脈衝 / 盾。
共用工具：src/brains/lib-alpha.js（挑目標、危險度、16 方向選路、閃避、繞建築）

## 第 1 輪：配裝 + 大腦 v1
- 配裝 v1：標準頭 / 標準軀幹 / 雙足 / 左打樁拳 / 右光束劍 / 雙背火箭莢艙 / 全陶瓷
- 大腦 v1：
  - 挑獵物：距離 + 血量 / 35 + 身邊 6 格內同伴數 × 1.6；狙擊 / 拋射 / 飛彈類 −2；自爆機 +6；看不到 +5；咬住的目標 −3（不亂換）
  - 遠（> 5.5 格）架火箭「火箭開路」（近 / 對方慢 / 失衡才打）；近換回手臂：光束劍（範圍掃）、打樁拳
  - 移動：直衝獵物（> 7 格小幅之字），貼臉後繞著它轉；4.5–11 格、能量 ≥ 45 → 往獵物推進「突進！」
  - 自爆機貼上來 → 拉開用火箭打；6 格內 4 台以上而且血 < 60% → 往危險最低、靠近獵物的方向「殺出重圍」
  - 閃：重彈 / 火箭 / 拋射物落點 / 衝鋒機衝過來（血 < 50% 才閃追蹤飛彈）
- gauntlet（seed 1、各 6 場）：26/30 = 87%；精英包 2/6（其他 4 包 6/6）
- 看紀錄：精英劍兵一刀 58 讓雙足失衡；真正打死我的是兩台精英步兵的機槍（每台 ~57/秒）

- 改：火箭只在 < 7 格或對方失衡時打，架火箭的距離上限 13 → 9
