# Brick Mecha（試玩場）

俯視角方塊機器人動作，以電腦版為主（鍵盤滑鼠或手把雙搖桿）。硬派但節奏輕快。Three.js 0.160、ES modules、不需要建置。

## 模式
- **主選單**：對戰、觀戰、試玩場、整備、操作說明
- **對戰**：一對一。選對手（突擊型、狙擊型、光束型、重砲型、隨機）和難度，打倒對手勝利、被打倒敗北，結束後可以再戰、換對手、整備
  - 難度（src/ai.js `DIFFS`）：新手（敵機傷害 ×0.45、耐久 ×0.7、射擊間隔 ×2、瞄準晃很大、不會閃避）／普通（×0.7、×0.85、×1.3）／強敵（全力）
- **觀戰**：電腦對電腦（藍方 vs 紅方，強敵難度）。每台一半機率是現成配裝、一半是隨機組裝（`randomLoadout`：至少兩把武器、不超重），打完 4.5 秒後自動換一組重開；畫面上方記比分、下方顯示兩台的部位狀態和武器
- **試玩場**：兩台敵機、被打爆會補新的；敵機一開始停火，T 切換開火；R 修復自己；自己被打爆會重新出擊

## 操作
- WASD 移動、滑鼠瞄準、左鍵 / 右鍵 = 左右手武器、Q / E = 左右背武器、Space / Shift = 推進衝刺
- G 整備（組裝機體）、Esc 暫停；試玩場：R 修復機體、T 敵機停火 / 開火
- 手把：左搖桿移動、右搖桿瞄準、LT / RT 左右手、LB / RB 左右背、A 衝刺、Back 整備、Y 修復、Start 暫停

## 機體組裝（src/parts.js）
機體 = 頭 + 軀幹（含雙臂）+ 腳 + 四個掛載點 + 各部位的裝甲種類。數值由 `computeSpec` 從零件算出。
- **頭**：視野角度與距離、雷達範圍、鎖定（時間、同時幾台、距離）、敵情（看得到目標的配裝名稱和裝甲）
  - 標準感測頭、全周雷達頭（360°）、狙擊感測頭（窄而遠、鎖得快）、多重鎖定頭（同時鎖 6 台、沒有敵情）
- **軀幹**：耐久、手臂負重、背部負重、上半身轉速（標準 / 輕量 / 重裝）
- **腳**：總負重上限、極速、加速、下半身轉速、衝刺強度
  - 雙足、逆關節：人類一樣的腳法，往任何方向走
  - 履帶：只能沿車身前後開、原地旋轉，抓地力強、扛得重
  - 懸浮：到哪都有點滑，泥地不影響，衝刺強
- **超重不禁止**：總重超過腳的負重 → 變慢；手臂超重 → 上半身轉得慢、子彈較散；背部超重 → 能量回復變慢
- 配裝存在瀏覽器（localStorage）

## 武器（src/weapons.js）
| 掛載 | 武器 | 屬性 | 特色 |
|---|---|---|---|
| 手 | 機槍 | 動能 | 高射速、低傷害 |
| 手 | 機砲 | 動能 | 中射速、中傷害 |
| 手 | 霰彈槍 | 動能 | 一次 8 發、射程短 |
| 手 | 狙擊槍 | 動能 | 單發高傷、彈速極快、留下彈道煙 |
| 手 | 光束步槍 | 能量 | 吃能量、不用換彈 |
| 手 | 光束劍 | 能量 | 吃能量；往前突進揮一刀，打中扇形內的敵機，順便劈掉飛來的子彈 |
| 背 | 加農砲 | 動能 | 重擊、擊退大、自己也被後座力推 |
| 背 | 直射飛彈 | 化學 | 一次 2 發，有鎖定就追蹤 |
| 背 | 垂直飛彈 | 化學 | 一次 4 發，先往上再從上方砸（越過掩體、容易打到頭和背部），要鎖定 |
| 背 | 分裂飛彈 | 化學 | 飛一段後裂成 6 顆小追蹤飛彈 |

能量條同時給推進衝刺和光束武器用。

## 屬性剋制
| 裝甲 | 擋 | 怕 |
|---|---|---|
| 複合（深灰） | 動能 | 化學 |
| 陶瓷（白） | 化學 | 能量 |
| 鏡面（淡藍、微亮） | 能量 | 動能 |

剋制 ×1.4、被擋 ×0.65。裝甲按部位選（頭、軀幹、手臂、腳；背部武器用軀幹的裝甲）。被擋下時火花是藍白色，剋制時火花更多更大。

## 部位破壞（src/mech.js `hitMech`）
看子彈從哪個方向打來：正面打軀幹（×0.75，兩成打到頭）、側面打那一側的手臂、背面一半打到背部武器、其他打軀幹弱點（×1.4），另有一成五打到腳。
- 頭：沒了視野剩 60°、8 格，沒有雷達、鎖定和敵情，上半身轉得慢、子彈散
- 手臂 / 背部：那把武器沒了
- 腳：越傷越慢，壞了只剩 35%、拖著走
- 軀幹：沒了就爆炸
- 半血以下冒煙、1/4 以下冒小火、壞掉的斷口持續燃燒

## 感測（src/sensors.js）
- 視野：地上淡淡的扇形 = 頭的視野。視野外（或被方塊擋住）的敵機整台隱形，只有雷達範圍內會定期亮紅色光點；身邊 3 格內一定看得到。子彈不受影響，看得到
- 鎖定：準星附近、視野和鎖定距離內的敵機會慢慢鎖上（琥珀色框縮小），鎖上變紅色。直射 / 分裂飛彈追鎖定目標，垂直飛彈一定要鎖定

## 其他
- **慣性與摩擦**：腳只能靠抓地力改變速度，每秒最多改變 min(腳的加速, 地面摩擦 × 抓地力)；地面有混凝土、冰面、泥地
- **推進衝刺**：花 30 能量，瞬間加速、不受抓地力限制
- **碰撞**：撞牆太快會受傷；兩台高速互撞兩邊都受傷，重的那台吃虧少
- **特效**（src/fx.js）：全部用方塊（發光方塊、煙 / 塵方塊兩個共用的 InstancedMesh）
- **敵機**（src/ai.js）：隨機挑一套配裝（突擊型、狙擊型、光束型、重砲型），依武器決定距離；狙擊開槍前會亮紅色雷射；看到重彈 / 飛彈飛來會往旁邊噴開；被打爆後新的一台從天上降落

## 檔案

- `src/weapons.js` 武器與彈藥
- `src/sensors.js` 視野、雷達、鎖定
- `src/garage.js` 整備畫面
- `src/ai.js` 敵機
- `src/arena.js` 場地、地面種類、碰撞
- `src/input.js` 鍵盤滑鼠與手把
- `src/fx.js` 粒子；`src/voxel.js` 方塊模型；`src/audio.js` 合成音效
