# Brick Mecha（試玩場）

俯視角方塊機器人動作，以電腦版為主（鍵盤滑鼠或手把雙搖桿）。Three.js 0.160、ES modules、不需要建置。

目前只有一個試玩場，用來驗證兩件事：慣性移動的手感、部位破壞。

## 操作
- WASD 移動、滑鼠瞄準、左鍵 = 左臂機砲、右鍵 = 右臂加農砲、Space / Shift = 推進衝刺
- R 修復機體、T 敵機停火 / 開火、Esc 暫停
- 手把：左搖桿移動、右搖桿瞄準、LT / RT 左右臂、A / LB / RB 衝刺、Y 修復、Start 暫停

## 機制
- **慣性與摩擦**（src/mech.js `driveMech`）：腿只能靠抓地力改變速度，每秒最多改變 min(腿力 ACC, 地面摩擦 μ × GRIP)。放開方向鍵不會立刻停，會滑一段；腿在滑的時候不踏步。
- **地面**（src/arena.js `SURF`）：混凝土（一般）、冰面（μ 很低，加速、煞車、轉向都很滑）、泥地（極速 ×0.55、阻力大，衝刺很快被吃掉）。
- **推進衝刺**：花 30 能量，瞬間加一段速度、持續推 0.22 秒，不受抓地力限制；之後靠摩擦收回來。能量停用 0.6 秒後回復。
- **上下半身分開**：腿朝移動方向轉、上半身朝瞄準方向轉，各有轉速；加速會往後仰、煞車往前傾。
- **後座力與擊退**：加農砲會把自己往後推、把對方推走；機砲幾乎沒有。
- **碰撞**：撞牆法向速度超過 6 會傷到腿和軀幹；兩台機體相對速度超過 5 互撞，兩邊都受傷（跑得快的那台少受一點）= 衝撞攻擊。
- **部位破壞**（`hitMech`）：看子彈從哪個方向打來——正面打軀幹（裝甲，傷害 ×0.7，兩成打到頭）、側面打那一側的手臂、背面打軀幹弱點（×1.5），另有一成五打到腿。
  - 頭：沒了瞄準線消失、上半身轉得慢、子彈散布變大
  - 手臂：沒了那把武器就不能用
  - 腿：越傷越慢，壞了只剩 35% 速度、拖著走
  - 軀幹：沒了就爆炸
  - 半血以下冒煙，壞掉的冒黑煙、噴火花
- **特效**（src/fx.js）：全部用方塊。兩個共用的 InstancedMesh（發光方塊、煙 / 塵方塊），顏色照色帶隨時間變。
  - 擊中：一下閃光 + 往子彈來的方向彈回的火花（有重力、會在地上彈）；打在正面裝甲上是藍白色火花；加農砲打中多一個小爆炸
  - 部位：半血以下冒煙、1/4 以下冒小火；壞掉的斷口持續燃燒、飛火星、冒黑煙；炸掉時一個小爆炸
  - 爆炸：閃光 → 往外炸開又很快停住、慢慢上浮的火球方塊 → 地面一圈塵 → 火星 → 晚一點冒出的黑煙柱；機體被打爆時連炸兩下，殘骸再燒 5 秒
- **敵機**（src/ai.js）：同一套物理；保持中距離繞圈、看到加農砲彈飛來會往旁邊噴開；機砲一陣一陣打、加農砲幾秒一發，子彈比玩家慢、看得到。被打爆 2.5 秒後，新的一台從天上降落（地上先出現紅圈，站在下面會被砸）。
- 畫面左下：自己的部位狀態、武器、能量、腳下地面與速度；右下：準星附近敵機的部位狀態。

## 檔案
- `src/mech.js` 機體模型、物理、部位傷害
- `src/weapons.js` 武器與砲彈
- `src/ai.js` 敵機
- `src/arena.js` 場地、地面種類、碰撞
- `src/input.js` 鍵盤滑鼠與手把
- `src/fx.js` 粒子、煙、推進火焰；`src/voxel.js` 方塊模型；`src/audio.js` 合成音效
